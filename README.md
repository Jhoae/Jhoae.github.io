## Backend Developer

안녕하세요. 문제의 원인을 추측하기보다 실제 호출과 데이터 흐름을 확인하고, 선택한 기술의 이유와 트레이드오프를 설명하려는 백엔드 개발자 오재호입니다.

AIRS 프로젝트에서 MQTT telemetry 수집, MySQL과 InfluxDB의 역할 분리, Redis를 활용한 캐시와 데이터 정합성 처리, 인증·권한, 테스트와 배포를 경험했습니다. 운영과 분리된 환경에서 병목을 재현하고 코드·로그·저장 결과로 검증하며, 확인하지 못한 범위는 과장하지 않는 개발 방식을 중요하게 생각합니다.

현재 AIRS의 코드와 실험 결과를 다시 공부하며, 문제·분석·선택·구현·검증 과정을 직접 설명할 수 있는 백엔드 개발자로 준비하고 있습니다.
