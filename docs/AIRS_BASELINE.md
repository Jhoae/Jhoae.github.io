## 기준 적용 원칙

- 현재 `main` 코드와 이 commit을 포트폴리오 코드 근거로 사용합니다.
- 로컬에서 새로 작성한 포트폴리오 문서는 AIRS backend 코드 기준에 포함하지 않습니다.
- 문서와 코드가 충돌하면 이 commit의 코드와 실제 검증 결과를 우선합니다.
- `구현`, `테스트`, `실측 검증`, `향후 계획`을 서로 다른 상태로 기록합니다.
- 종료 후 실행하지 않은 실험은 실제 결과로 사용하지 않습니다.
- 실제 센서, Raspberry Pi, 장시간 운영에 대해 이 기준이 증명하지 않은 성능을 주장하지 않습니다.
- 원본에 감지된 license가 없으므로 fork에 별도 오픈소스 license를 임의로 추가하지 않습니다.
